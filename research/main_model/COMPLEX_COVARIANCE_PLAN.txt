Exact map for n complex pairs x_j=(real_j,imag_j)^T:
  C = (1/n) sum_j x_j x_j^T
  rho = 1/16, epsilon = 2^-23
  M = (1-rho) C + rho*trace(C)/2 I + epsilon I
  y_j = M^(-1/2) x_j, using the positive symmetric inverse square root.

is not this token-local uncentered shrinkage map. This is a separate variant.
