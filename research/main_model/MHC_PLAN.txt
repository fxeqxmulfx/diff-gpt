mHC paired comparison, declared before training, 2026-11-08

Question: does four-stream dynamic manifold-constrained routing improve the
current complex-peri-rms-ordinary-v1 main model on the frozen short/long suites?

Two arms: main (current exact mathematical model), mhc (only residual routing
changed). Both use ordinary causal inverse-width SSMax, Q/K RMS, standard RoPE,
plain complex-product FFN, tied raw embedding/readout, parameter-free Peri-RMS
and embedding/final RMS. No XSA, centering, radial sigmoid, or LR search.

mHC follows arXiv:2512.24880v2 section 4.2 and the local native Lean adaptation
Transformer.MHC.PeriRMS: four copied embedding streams; separate dynamic router
for attention and FFN; flattened 4D RMS; projections to 4 read, 4 write and 16
skip logits; learned scales and static biases; sigmoid reads, twice-sigmoid
writes, twenty column-then-row Sinkhorn cycles; unweighted final stream mean.
The existing 1/sqrt(2L) branch coefficient is after branch RMS, before writing.
Router RMS epsilon is the main model's 2^-23. Sinkhorn uses log space and FP64
normalization/recomputed adjoints, without denominator epsilon. FP32 storage
remains; no claim of exact floating-point double stochasticity.

Initialization: base model parameters are bit-identical between arms, with the
original native seed. Additional router projections use a separate seed+20000
native Random Gaussian(0,.02); all three dynamic scales start at .01 as in the
paper. Read/write biases start at zero, skip biases at 2I (identity preference).
The paper does not prescribe these projection/bias details; this is one explicit
adaptation, frozen here. All added parameters train with the existing AdamW,
including its decay. Real router projections are unconstrained; the existing
complex projection ties are unchanged. Added parameters: 2L*(96D+27).
