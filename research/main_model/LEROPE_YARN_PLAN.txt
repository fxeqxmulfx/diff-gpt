Preparation, 2026-11-09. Control selection waits for covariance closure.

The language-paper LeRoPE learns alpha_j, with omega_j=base_j*exp(alpha_j),
shared across heads/layers. Keep the selected main's initialization, optimizer,
normalization positions, tied embedding and every other model component.
The inference-only YaRN rule uses r_j=Ltrain*omega_j/(2*pi),
w_j=clamp((r_j-1)/31,0,1), u=min(1,Ltrain/Ldoc),
omega'_j=omega_j*(u+w_j*(1-u)),
g=(1+0.1*ln(max(1,Ldoc/Ltrain)))^2.
Multiply the COMPLETE real attention score by g before softmax. Do not scale
Q/K amplitudes: that would scale the squared-imaginary term differently.
GPU frequency/ramp/rotation and score math stay FP32; no dynamic precision
fallback, no GPUFP64, no parameter readback in the forward path.

Training has no YaRN intervention. An unextended document must use the exact
original forward path and rotation table. Reject backward/optimizer calls
while the inference extension is configured; there is no claimed training
derivative through its clamped frequency map. Never fabricate a smaller
Ltrain to obtain a nonidentity transformation, or claim a training-epoch gain
from this inference-only mechanism.

Two-dimensional DiffGPT proposal
Axial, not mixed image RoPE: half of each head's complex pairs encode time,
half encode feature. Flatten in row-major order p=t*F+f, retaining the ordinary
causal mask. Let m=d/4, with d the REAL head width, divisible by4. Each axis
uses base_j=10000^(-j/m), j=0..m-1, and its own zero-initialized log multiplier.
There remain d/2 parameters total, shared across heads/layers. Time angle is
t*omega_j; feature angle is f*nu_j. No extra parameters or RNG draws.
An F=1 case has zero feature angles and cannot establish a feature-axis benefit.
Require a separate multi-feature case with fixed feature order. Feature indices
are a modeling convention, not a proven spatial metric.
During context extension apply YaRN only to time bands, using the true training
time extent and declared inference time extent. Keep feature bands unchanged;
apply g once to the complete score. No updates through inference YaRN.
Ordinary 1D and axial2D are independently labeled controls/candidates. Train
all requested encoders MASH,LGT,MASH-half with matched native splits, seeds,
budgets and decoded metrics; no pooling away an encoder regression.
The exact DiffGPT dataset/seed/budget registration is a separate prerequisite
to scientific training. Existing codec tests are not model-learning evidence.
