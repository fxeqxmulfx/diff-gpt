Diagonal failure, complex product and XSA: Lean review, 2026-11-08

The next controlled architecture test should retain the plain complex-product
FFN and replace Hermitian XSA with ordinary causal attention, keeping SSMax,
QK normalization, Peri/embedding RMS, residual scaling and tied weights. The
specific reason is equal-value cancellation in the attention projection. No
no-XSA training has been performed in this review, and no99% fix is claimed.

Exact attention mechanism
For tokens [a,a], the embedding and every pre-attention token-wise operation
produce equal states. RoPE rotates Q/K; it does not rotate the values. Hence
v_1=v_2=v. Whatever QK normalization, SSMax and RoPE do to the probabilities,
their normalized weighted sum is y=(p_1+p_2)v=v. Ordinary attention retains v.

Hermitian XSA subtracts the complex projection onto the current value:
  z = y - v * (<v,y>/||v||^2).
When y=v and v is nonzero, z=0. In real coordinates the implementation removes
the projections onto both v and Jv; the latter has zero coefficient here.
The same cancellation already occurs with the real XSA projection. Merely
replacing Hermitian XSA with real XSA would retain this diagonal mechanism.

Native denominator clipping matters: this exact argument applies when the
value norm exceeds1e-12. The implementation's prefix/guard code records that
condition. For shared prefixes it explicitly skips the attention residual,
zeros that branch's backward signal and shares the token-wise FFN/output path.
This stabilizes an exact cancellation; it is not evidence of a new gradient
implementation bug. First-position attention is also explicitly suppressed.
Changing only the XSA projector while retaining those shortcuts would NOT
implement ordinary causal attention. Both first/shared attention suppression
and their adjoint masks must be handled in the ablation.

What this does and does not imply
The diagonal still reaches the residual and FFN, so the complete model can
represent a unary rule a -> (2a)^4. Cancellation does not prove that XSA causes
the99% miss, or that the FFN cannot learn it. It identifies a concrete path
used by unequal operands that disappears for equal operands, motivating a
matched ablation. Extra FFN width/depth would not restore that attention path.
Ordinary attention with identical values also remains insensitive to their
count, so removing XSA alone does not solve every repeated-token/counting task.
No optimality or universal convergence guarantee follows.

The CP1 bridge uses x=N(E[a]+iE[b]) and an attention-free normalized residual
block. At a=b this input is proportional to(1+i)E[a], not zero. Plain
multiplication gives g*g/sqrt(2), nonzero for nonzero scalar g. This does not
guarantee a nonzero learned output projection or correct target features; it
does rule out an intrinsic equal-factor cancellation in the product itself.
The theorem's actual residual formula differs from our XSA transformer.

The new FiberCodes results prove that the classifier need only preserve
answer-class score contrasts. Recovering every Fourier feature is unnecessary:
errors can cancel inside an answer class. The committed explicit arithmetic
example is CUBIC modulo97, not this quartic task. The generic theorem applies
to any answer map, including s->s^4, once its isometry/alignment premises hold.
For quartic answers the equivalence is s=r*t for r in{1,22,75,96}, including
zero. The local checked file proves this factorization/equivalence and applies
the generic fiber theorem to the normalized Fourier basis at sums1 and22.
Distinct features have identical complete quartic class-score vectors.

These readout constructions do not supply trained tied-embedding weights.
Source alignment, a separating margin, recovery/objective conditions and
execution bounds remain premises. The new approximate-recovery bound tracks
alignment error plus conditioned fitting/objective error plus numerical error;
it does not show AdamW makes those errors small. A failed full-character probe
would therefore be insufficient evidence for replacing complex multiplication.
No such feature-recovery probe was run on the new plain checkpoint here.
