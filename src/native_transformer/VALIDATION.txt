Interface and checkpoint policy
DiffGpt creation and checkpoint loading accept only axial time x feature
LeRoPE. Forecasting uses inference-only YaRN beyond the saved actual training
time extent. Feature-axis frequencies remain unchanged. Generic Model retains
1D LeRoPE and explicit context experiments. Existing 1D checkpoints are never
silently reinterpreted. MASH, LGT and MASH-half are supported.

Training uses FP16 forward affine operands, TF32 backward affine operands and
FP32 accumulation, norms, master weights and moments. All 23 embedded PTX
modules contain no GPU FP64 instructions. There is no dynamic precision fallback.
CPU decoding uses binary64/exact rational references. Buffered checkpoint
cadence is at least 500 actual training epochs, plus initialization, requested
milestones, budget completion and explicit stop.

Learning results and limits
The selected generic main retained 75/75 short and 30/30 long passes. Versus
its phase-mHC parent, geometric-mean short epochs decreased 1.0718% and long
epochs increased 0.9485%; all 19 individual regressions remain recorded.
The final axial 2D candidate also retained 105/105, but short epochs increased
2.6083% and long epochs increased 8.9977% versus the selected main. It was not
promoted; all 24 individual regressions remain recorded.

The separate DiffGPT experiment completed and independently audited all 36
registered runs: three encoders, one/two features, three seeds, and 1D/2D.
Every run exhausted 5000 updates without reaching 90% decoded whole-row
accuracy. Best 2D endpoint: 89.328231%, MASH-half, F1, seed 17. F2 results
were poor, and longer-context results do not establish useful extrapolation.
No first90 epoch ratio exists. The 2D-only interface is a user preference,
not a claim that these learning failures were solved. Detailed final pairs:
